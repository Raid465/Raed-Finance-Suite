# ETF UI Style

Classic dark financial dashboard. No glassmorphism, no large gradients, no blur-heavy surfaces.

## Core tokens
- Page: `#0f1117`
- Surface: `#1a1d2e`
- Card: `#222640`
- Input: `#2a2e4a`
- Border: `#2e3350`
- Text: `#e8e8f0`
- Muted text: `#a0a0b8`
- Primary blue: `#4f8cff`
- Success: `#34d399`
- Danger: `#f87171`
- Warning: `#fbbf24`
- Radius: 6 / 8 / 12 px

## Rules
1. English is the default language on every fresh page load.
2. Arabic remains available via a language toggle and switches to RTL.
3. Cards use solid dark fills and subtle borders.
4. Primary actions use blue; green/red are reserved for financial status.
5. Focus states use a 2px blue outline for keyboard accessibility.
