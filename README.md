# Raed Finance Suite

The root folder is intentionally kept simple.

## Normal use

- `Start Raed Finance.bat` — starts the full Finance Suite and opens the dashboard.
- `Run Tests.bat` — runs the complete automated test suite. Start the site first and keep its window open while the tests run.

## Technical files

All application source code, launchers, automated tests, design-system files, and audit documentation are stored inside:

`project/`

You normally do not need to open that folder unless you want to edit or inspect the source code.
